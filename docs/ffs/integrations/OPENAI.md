# OpenAI Integration

## Purpose

OpenAI may be used as an optional intelligence provider for Max Core.

## Important Rule

Max Core must not depend permanently on OpenAI.

If subscription or API access is unavailable, the FFS operating system must still survive through documentation, local tooling, and alternate providers.

## Allowed Uses

- Planning
- Drafting
- Code generation
- Review
- Reasoning support

## Restricted Uses

OpenAI must not be the only place where FFS memory, policy, workflow, or architecture exists.

## Secret Rule

Never commit OpenAI API keys.
