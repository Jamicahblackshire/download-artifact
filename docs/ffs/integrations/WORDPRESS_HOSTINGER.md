# WordPress / Hostinger Integration

## Purpose

WordPress and Hostinger support the public FFS website.

## Target Uses

- Website pages
- Booking pages
- Service descriptions
- Lead capture
- Public trust layer

## High-Risk Actions

- Editing live checkout pages
- Changing booking/payment flow
- Plugin updates on production
- Theme changes on production
- DNS/domain changes

## Required Documentation

Every major website change must record:

- Page changed
- Reason for change
- Risk level
- Test method
- Rollback method
