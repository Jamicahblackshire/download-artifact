# FFS Workflow Index

## Purpose

This index defines the major workflows Max Core must understand for Fully Functional Solutions.

## Core Workflows

- GitHub workflow
- Deployment workflow
- Railway workflow
- Cloudflare workflow
- n8n workflow
- Website workflow
- Payment workflow
- Lead intake workflow
- Incident response workflow

## Operating Rule

Every workflow must define purpose, trigger, steps, risk level, approval requirement, test method, and rollback method.
