# GitHub Workflow

## Purpose

GitHub stores source code, documentation, branch history, Max Core policy, and FFS operating memory.

## Standard Flow

1. Create a focused branch.
2. Make one controlled change set.
3. Verify files.
4. Commit clearly.
5. Push branch.
6. Review before merge.

## High-Risk Actions

- git push
- force push
- deleting branches
- merging into production
- committing secrets
