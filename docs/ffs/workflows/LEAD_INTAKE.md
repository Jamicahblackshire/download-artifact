# Lead Intake Workflow

## Purpose

Defines how customer leads move through Fully Functional Solutions.

## Target Flow

Customer inquiry -> Website/form -> n8n intake -> CRM/contact record -> Service classification -> Jay/provider notification -> Customer follow-up -> Booking/payment -> Completion -> Record update

## Service Classification

- Precision Auto Diagnostics & Services
- JT Mobile & PC Unlocking
- The Clarity Session
- Sophia's Transportation Service
- General FFS inquiry

## Rule

Customer data is sensitive and must not be exposed in public logs or GitHub.
